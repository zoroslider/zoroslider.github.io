v1.0.0

major AddedChangedFix
June 28, 2026

Added

  • Introduced the Zoro Slider visual builder for creating sliders, carousels, galleries, hero sections, and media-rich presentations.
  • Added manual builder slides, Posts source, JSON Import source, and YouTube Playlist source workflows.
  • Added local and remote template discovery with preview, import, duplicate-import protection, and installed-template detection.
  • Added addon discovery and remote addon installation support, including license-aware download gates.
  • Added per-slide guides, grid settings, and vertical or horizontal layout columns for builder layout planning.

Changed

  • Improved dashboard, sliders, templates, and addons screens with clearer cards, badges, filters, previews, and management actions.
  • Moved premium-adjacent capabilities toward addon-friendly workflows so the core plugin can stay more focused.

Fixed

  • Improved frontend and preview consistency for text, captions, HTML, button layers, Google Fonts, and source-driven placeholders.
  • Hardened import/export, AJAX requests, remote requests, output escaping, packaging, and release-readiness checks.

v0.9.0

minor AddedChangedSecurity
June 18, 2026

Added

  • Added remote template, slider, and addon catalog examples for controlled distribution from the Zoro Slider server.
  • Added license-aware download examples for free and pro remote assets.
  • Added fallback screenshot handling for missing catalog images.
  • Added standalone PHP endpoint examples for catalog, preview, protected download, and rate limiting.

Changed

  • Standardized remote demo preview paths so each preview bundle lives in its own previews/{demo-id}/ directory.
  • Updated remote asset examples to use the current themecresthq.xyz/plugins/zoroslider public URL structure.

Security

  • Added endpoint rate limiting examples to reduce repeated catalog, preview, and download abuse.
  • Added safer duplicate-install guards before remote package download requests are made.

v0.8.0

minor AddedFix
June 5, 2026

Added

  • Added multiple layer selection, grouping, ungrouping, grouped dragging, and history logging for grouping actions.
  • Added keyboard shortcut documentation and platform-aware shortcut labels for Windows and macOS.
  • Added context menu documentation and translatable builder context menu labels.
  • Added guide, grid, and layout column persistence per slide.

Fixed

  • Fixed builder ruler positioning when the right settings panel opens and when toggling fullscreen mode.
  • Fixed Google Font loading on hard reload for text and button layers.
  • Fixed guide dragging across slides and added safer guide clearing workflows.

Overview

Zoro Slider is a WordPress slider and visual builder plugin for creating animated sliders, carousels, galleries, and media-rich hero sections.

What You Can Build

  • fixed-size sliders
  • full-width sliders
  • full-screen sliders
  • scoped full-width layouts
  • carousels and gallery-style presentations
  • layered marketing banners
  • image, video, audio, and mixed-media slides

Core Features

  • visual drag-and-drop builder
  • slide manager with multi-slide projects
  • layer-based design workflow
  • transition and autoplay controls
  • thumbnails, dots, numbers, controls, and progress indicators
  • import and export tools
  • WordPress shortcode publishing
  • manual, Posts, JSON Import, and YouTube Playlist source types
  • local and remote template library with preview and duplicate-import protection
  • addon library with Free/Pro discovery and protected installation
  • per-slide guides, grid, and vertical/horizontal layout columns

Layer Types

You can add these layer types inside the builder:

  • text and HTML
  • image
  • audio
  • video
  • shape
  • button
  • icon

Media Sources

Zoro Slider supports:

  • WordPress media library files
  • HTML5 audio and video sources
  • YouTube video layers and background videos
  • Vimeo video layers and background videos
  • Google Fonts for text styling

Templates and Addons

Zoro Slider includes separate Templates and Addons admin pages.

  • Templates combines installed designs with remote Free and Pro catalog items.
  • Addons combines installed WordPress addons with the remote addon catalog.
  • stable IDs prevent repeatedly importing the same remote template after it is renamed locally.
  • library refresh actions update cached catalog metadata and screenshots.
  • protected downloads use purchase-code verification through the License Manager workflow.

Project Hierarchy

Zoro Slider works in three main levels:

Slider

The slider is the top-level project. It controls the overall behavior and presentation of the full slider output.

Slider-level options include:

  • layout mode
  • width and height
  • transition type
  • autoplay
  • loop
  • responsive behavior
  • navigation systems
  • carousel behavior
  • loader style
  • progress indicators

Slide

Each slider contains one or more slides. A slide is one screen or frame inside the slider.

Slide-level options include:

  • slide background color
  • slide background image
  • slide background video
  • slide-specific content composition
  • the collection of layers placed on that slide

Layer

Layers are the individual items placed inside a slide. These are the visible design and content elements that users see and interact with.

Layer-level options include:

  • position
  • size
  • content
  • typography
  • colors
  • spacing
  • borders and shadows
  • entrance and exit animations
  • timing
  • hover styles
  • actions

External Services

Review the optional external services used by Google Fonts, YouTube Playlist, JSON import, and Vimeo-enabled media features in Zoro Slider.

External Services

Zoro Slider can connect to external services only when you use the features that require them.

Google Fonts

Used for:

  • rendering selected Google font families in text, caption, and button layers

When it is used:

  • when a slider uses a Google Font on the front end
  • when the builder loads Google Font previews for selected fonts in admin

Related endpoints:

  • https://fonts.googleapis.com/
  • https://fonts.gstatic.com/

Privacy and terms:

  • https://developers.google.com/fonts/faq/privacy
  • https://policies.google.com/terms

YouTube Playlist

Used for:

  • the YouTube Playlist slider source type
  • pulling playlist items into source-driven slides
  • optional embedded video playback when you use placeholders such as {{video_embed}}

When it is used:

  • when a slider is configured with Source Type = YouTube Playlist
  • when preview or frontend rendering requests YouTube playlist items
  • when a rendered slide uses an embedded YouTube player

What is sent:

  • the configured playlist ID or URL-derived playlist ID
  • your YouTube Data API key
  • standard browser/request metadata handled by WordPress or the visitor browser
  • the selected YouTube video identifier when an embedded player is loaded

Related endpoints:

  • https://www.googleapis.com/youtube/v3/playlistItems
  • https://www.youtube.com/
  • https://www.youtube.com/embed/

Privacy and terms:

  • https://www.youtube.com/t/terms
  • https://policies.google.com/privacy

JSON Import

Used for:

  • the JSON import slider source type
  • pulling remote JSON feed items into source-driven slides

When it is used:

  • when a slider is configured with Source Type = JSON import
  • when preview or frontend rendering fetches the configured JSON endpoint

What is sent:

  • a normal outbound HTTP request from the WordPress site to the configured JSON URL
  • standard request metadata such as the server IP, user agent, and HTTP headers generated by WordPress hosting/network layers

Important note:

  • the plugin does not control the privacy practices of the remote JSON service you choose
  • site owners should only use trusted JSON endpoints

Related endpoints:

  • your configured JSON URL

Zoro Slider Remote Library and Licensing

Used for:

  • loading public template and addon catalog metadata
  • opening hosted template previews
  • downloading entitled slider, template, and addon packages
  • verifying the main product purchase code and, when applicable, a separately sold Pro-addon purchase code

When it is used:

  • when you open or refresh the Templates or Addons library
  • when you preview a remote catalog item
  • when you install or import a protected remote package
  • when License Manager verifies or supplies a saved purchase code

What can be sent:

  • purchase code
  • site URL
  • WordPress admin email used for request context
  • Zoro Slider and WordPress versions
  • selected template, slider, or addon ID

Catalog metadata can be visible without verification. Protected downloads are checked separately. Remote catalog screenshots use a server-provided fallback when an image is known to be unavailable, preventing requests to known-missing files.

Related endpoint base:

  • https://zoroslider.xyz/wp/plugins/zoroslider/

Purchase codes should be handled as credentials. Do not publish them, place them in screenshots, or send them through untrusted support channels.

Vimeo

Used for:

  • Vimeo video layers
  • Vimeo background videos
  • Vimeo embeds placed inside HTML layers where you intentionally use embed markup

When it is used:

  • when a slide or layer is configured to load Vimeo media
  • when an HTML layer contains a Vimeo embed

Related endpoints:

  • https://api.vimeo.com/
  • https://player.vimeo.com/

Privacy and terms:

  • https://vimeo.com/privacy
  • https://vimeo.com/terms

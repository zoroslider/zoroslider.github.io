Zoro Slider Standalone HTML Bundle
=================================

Slider: Beauty 1

How to use
----------
1. Extract this ZIP.
2. Upload the extracted folder to any web server or CMS file manager.
3. Open index.html in a browser or link to it from your site.

Notes
-----
- Local WordPress upload files used by this slider were copied into the media folder.
- The slider preview image was copied into assets/images as slider-preview.{extension}.
- Basic slider-level settings were exported to slider-details.json.
- External assets such as Google Fonts, YouTube, Vimeo, or remote JSON/media remain external.
